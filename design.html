About

Terra is a minimal ui framework that is inspired nature. Named after earth, it supports both light and dark mode. Respectively named sol and lunar.

While the default theme, Manuka emphasises light pastels and, rounded corners. It also provides materials that emulate real world concepts like paper and glass.

The base library is low ceremony staying true to the html spec for accessibility and easy learning curve. It is highly customizable by replacing the default theme with your own while keeping the same api spec. And allows to override or customise easily.

Layouts are different for each web application so Terra does not include any and allows you to compose the base elements to create and make your own bespoke designs.

It emphasises on brand language while using sans-serif for most use cases. Serif for long form content that reads more like magazines and blog posts.

Additional modules such as a terminal stylesheet allow to emulate CLI tools in the web while keeping the base library small and only neccessary for when it is needed.

For iconography, Terra uses Material Symbols to have uniform icons users will be familiar with and offers a wide scope of icons to use. However it is easily replaceable by simply replacing the icons as demonstrated below.
