Buttons

Buttons by default are borderless and on hover have a shade to fit the minimal nature of Terra. These can be altered through a custom theme or colour/utility classes.

The following demonstrates common icons that are used. Terra uses Material Icons by default to bring familiarity to the user for visual indication. However custom icon libraries can be used to replace it easily as Material Icons are imported before Terra.

Primary

Primary buttons intended to use a main brand colour and visually imply it is the main action are user should click on.

Terra uses the var(--primary-color)variable by default. But can be overrided with palette to indicate a secondary action etc.
